# 🔢 LabSeven - FizzBuzz

A classic programming exercise implemented in Java using Spring Boot. This lab demonstrates fundamental control flow, modular arithmetic, and clean code practices through the well-known FizzBuzz problem.

## 📋 Problem Statement

Print numbers from 1 to 100 with the following rules:
- For multiples of **3**, print `Fizz` instead of the number
- For multiples of **5**, print `Buzz` instead of the number
- For multiples of **both 3 and 5**, print `FizzBuzz`
- Otherwise, print the number itself

## 🚀 Features

- **Clean Implementation** - Uses efficient conditional logic
- **Java Best Practices** - Follows standard Java coding conventions
- **Spring Boot Framework** - Built on Spring Boot with embedded server
- **Console Output** - Prints results directly to the console

## 🏃 Getting Started

### Prerequisites

- JDK 11 or higher
- Maven 3.6+

### Installation

```bash
# Clone the repository
git clone https://github.com/MuskaanSultana/LabSeven.git

# Navigate to project directory
cd LabSeven

# Build the project
mvn clean install

# Run the application
mvn spring-boot:run
```
